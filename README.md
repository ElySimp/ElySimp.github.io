# ElySimp.github.io

Visual engineering portfolio for **Faldo Maxwell** (`ElySimp`), built with static HTML5, CSS3, and vanilla JavaScript for GitHub Pages.

## Highlights

- **MaoCAT (HSK Quest):** System architecture diagram, 4 Android UI screens, and interactive benchmarks for MobileNetV2, Dual-Head ToneNet, and the 16 KB CAT scheduler.
- **HomePoker Leaderboard & GTO Hub:** Interactive leaderboard and 13x13 GTO range lab views.
- **Sentiment Analysis XAI:** LIME local explanation and LinearSVC vs. Naive Bayes evaluation plots.
- **BMKG 2024 Data Warehouse:** Interactive SVG bar chart backed by verified 2024 monthly CSV totals across 5 West Java stations, paired with the MySQL Star Schema diagram.
- **Accessibility & Performance:** Light and dark themes, responsive layout across laptop and phone viewports, keyboard-navigable lightbox modal, and intrinsic image dimensions.
